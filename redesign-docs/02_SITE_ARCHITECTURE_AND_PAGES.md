## 2. Page Template Taxonomy

Every page in the redesigned website adheres to one of **6 structural page archetypes**:

| Template Type | Layout Archetype | Best Suited For | Key Elements |
|---|---|---|---|
| **Archetype A** | **Portal Homepage** | Landing page (`index.html`) | Full-width hero banner, Marquee ticker, Metric counters, Tabbed programs, Principal message, Live notice board, Campus gallery, Quick links. |
| **Archetype B** | **Academic Department** | Department pages (Arts, Science, B.Ed.) | Left sidebar sub-nav, Department hero, Tab switcher: Overview, Faculty, Syllabus, Laboratories, Activities, Outcomes. |
| **Archetype C** | **Quality & Accreditation Hub** | NAAC & IQAC pages (`iqac.html`, `naac.html`) | Statutory banner, Criteria 1–7 pill selector, Year-wise accordion tables for AQARs, downloadable PDF lists, Online feedback forms. |
| **Archetype D** | **Admissions & Notices Center** | Admission lists & Circulars (`admission.html`, `notices.html`) | Filter bar (Year, Stream, Category), Live status badges, Table view with PDF direct downloads, Important instructions sidebar. |
| **Archetype E** | **Directory & Faculty Profile** | Faculty & Administration (`faculty.html`, `staff.html`) | Grid card layout with photo, designation, qualifications, email, subjects taught, and expandable profile drawer. |
| **Archetype F** | **Standard Informational / Statutory** | About Us, RTI, Facilities, Contact | Breadcrumb path, Article typography, Document embed/viewer, Contact card with map and quick form. |

## 3. Structural Comparison: Gurukripa Peeth Current vs. Redesigned (GMGCU Standard)

| Aspect | Current Gurukripa Peeth Site | Redesigned Standard (GMGCU Architecture) |
|---|---|---|
| **Header** | Single blue topbar with static social links | Dual-tier Academic Header with NAAC grade badge, Bilingual title, Helpdesk numbers, and statutory badges. |
| **Navigation** | Basic drop-down with scattered links | Institutional Sticky Mega-Menu with 12 logical academic clusters and mobile drawer. |
| **NAAC / IQAC** | Single empty dropdown item | Dedicated 8-section Quality Hub with Criteria 1–7, AQAR archives, IIQA/SSR, and Stakeholder ATRs. |
| **Admissions** | Static text without year-wise breakdown | Multi-year category-filtered Admission Portal (Provisional, Waiting, Admitted lists with PDF links). |
| **Programs** | Single page listing | Streamlined faculties (Arts, Science, Teacher Education) with syllabus, outcomes, and lab facilities. |
| **Student Corner** | External links in raw dropdown | Comprehensive Student Center with GGTU exam links, scholarship tracker, grievance redressal, ICC, and anti-ragging. |
| **Document Downloads** | Raw file directory links | Standardized document tables with PDF icons, file sizes, academic sessions, and search filters. |
| **Mobile Experience** | Basic responsive collapse | Touch-optimized off-canvas navigation with accordion menus and tap-friendly touch targets. |
